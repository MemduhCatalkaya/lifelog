# LifeLog

LifeLog is a personal, non-commercial Android application developed with Kotlin and Jetpack Compose.

The application is designed as a collection of independent modules for managing different aspects of everyday life.

## My Cinema

My Cinema is a personal movie and TV series management module.

### Features

- Personal movie and TV series collections
- Cast and genre management
- Posters, backdrops, and actor profiles
- Personal ratings, notes, and watch history
- Watchlists and episode tracking

TMDB integration is planned to retrieve movie and TV series metadata, cast information, and artwork.

## Privacy

LifeLog is developed for personal use only. The application is not commercially distributed, and its source code is not publicly available.
